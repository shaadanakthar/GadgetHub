\# GadgetHub 🛒



A full-stack electronics e-commerce web application built with React, Node.js, Express, and MongoDB.



\## Features



\- Browse and search products

\- User registration and login

\- Shopping cart functionality

\- Product management through an admin dashboard

\- MongoDB database integration

\- Product image uploads



\## Tech Stack



\*\*Frontend\*\*

\- React.js

\- Tailwind CSS

\- CSS



\*\*Backend\*\*

\- Node.js

\- Express.js

\- MongoDB

\## Getting Started



\### 1. Clone the repository



```bash

git clone https://github.com/YOUR\_USERNAME/GadgetHub.git

cd GadgetHub

```



\### 2. Install backend dependencies



```bash

cd backend

npm install

```



Configure your MongoDB connection and other required environment variables before starting the server.



\### 3. Install frontend dependencies



Open a second terminal:



```bash

cd frontend

npm install

npm start

```



Follow the backend startup command defined in `backend/package.json`.
